# Fawry Daily Report — نسخة مصدر أولية

## المتطلبات
- Node.js إصدار حديث
- مشروع Supabase
- Project URL وPublishable Key

## التشغيل
1. فك ضغط الملف.
2. انسخ `.env.example` إلى ملف جديد اسمه `.env`.
3. ضع رابط المشروع في `VITE_SUPABASE_URL`.
4. ضع Publishable Key في `VITE_SUPABASE_ANON_KEY`.
5. افتح Terminal داخل مجلد المشروع وشغّل:
   ```bash
   npm install
   npm run dev
   ```

## تنبيهات مهمة
- هذه نسخة مصدر أولية للربط والاختبار وليست نسخة إنتاج نهائية.
- لا تضع Secret Key أو service_role في الواجهة أو ملف `.env`.
- يجب اختبار تسجيل الدخول وسياسات RLS والتخزين بحساب موظف ومدير وSuper Admin قبل الاستخدام الفعلي.
- وظائف تعديل التقارير وتغيير كلمة المرور وإدارة المستخدمين وتصدير Excel المدمج بالصور لم تكتمل بعد.
- لا تستخدم بيانات عملاء حقيقية قبل مراجعة الأمان وإكمال الاختبارات.
- قاعدة البيانات تفترض وجود الجداول والسياسات التي تم إعدادها مسبقًا في Supabase SQL Editor.
